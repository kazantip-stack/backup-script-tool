# Умный бэкапер папок с ротацией

Консольная утилита на чистом Python, которая создаёт архив указанной папки
в формате .tar.gz с датой и временем в имени файла, а затем автоматически
удаляет старые архивы, оставляя только заданное количество последних копий.

## Что умеет

- Архивирует любую указанную папку в .tar.gz
- Добавляет в имя архива дату и время создания
- Автоматически удаляет старые архивы, оставляя только N последних (ротация)
- Ведёт лог всех действий: успешные бэкапы, удаление старых архивов, ошибки
- Проверяет существование исходной папки перед началом работы
- Настраивается через аргументы командной строки — без правки кода

## Как запустить

Базовый запуск (сохранит архив в папку backups/, оставит 5 последних копий):

    python backup.py /путь/к/папке

С указанием своей папки для архивов и количества хранимых копий:

    python backup.py /путь/к/папке -d /путь/для/архивов -k 3

Если путь содержит пробелы — оборачивайте его в кавычки:

    python backup.py "C:\Users\Name\OneDrive\Рабочий стол\test_folder"

Посмотреть все доступные параметры:

    python backup.py -h

## Технологии

- Python 3.14
- Стандартная библиотека: os, tarfile, argparse, logging, datetime
- Без внешних зависимостей
